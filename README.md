A chromium-based browser extension that removes distractions from news websites so you can read without interruption. Supports sites like Nation Africa, Standard Media, and others.

---

### What it does

unBlocker is a general-purpose content filtering tool. It gives you control over what loads in your browser, including:

- Ads and sponsored content
- Comment sections
- Cookie banners and popups
- Paywalled content that is already delivered to your browser but hidden from view

This extension only reads content your browser has already received. Modifying how content renders in your own browser is the same principle behind ad blockers and reader modes.

---

### Installation

This extension is not listed on the Chrome Web Store and must be installed manually.

1. Download and unzip the extension folder
2. Open your (chromium-based) browser and go to `chrome://extensions`
3. Enable **Developer mode**
4. Click **Load unpacked** and select the extension folder
5. The extension is now active

To enable it on a site, click the extension icon and toggle it on for that page.
